Backup Mode

Database Access: Read-only via pg_dump
Storage: Cloudflare R2 / S3 bucket

What This Service Does

1. Read the configured source database.
2. Create a SQL dump file.
3. Upload the dump to object storage.
4. Keep only the last {{ retention_days }} days of backups.

Stored Backups

Backups are stored in object storage only. No restore action is available from this service.
